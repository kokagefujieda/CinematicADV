コードを読んで見直した結果のメモ。UE のビルド環境がないため、**実機での確認はまだしていない**。

## 現状の機能（実装されているもの）
- **Click Wait Track:** Loop（区間をループ）と Stop（区間の終わりで一時停止）。クリックすると区間の後ろへジャンプする。
- **長押しスキップ:** ゲージを表示し、黒にフェードしてからシーケンスを Stop する。
- **設定:** DataAsset（UCinematicADVConfig）を AssetRegistry から自動で探し、IMC と入力アクションを自動でバインドする。
- ADVDialogue Track / Section / EvalTemplate は**空のファイル**（予約だけ）。
- SequencerSubtitles は依存に入っているだけで、コードからは使っていない。

### SequencerSubtitles v1.4 との組み合わせ（仕様の注意）
- 字幕の退場がセクション内で完了するようになったため、**Click Wait の終わりと同時に終わる字幕は、クリックを待っている間にはもう消えている**。
- 字幕のセクションを「Click Wait の終わり＋退場の時間」まで伸ばしておけば、クリックした後に退場する。これが自然な作りになる。
- 作者向けに案内するか、Click Wait の終わりに字幕を揃える補助機能を付けるかを検討する。
- SQS v1.4 で、PIE 中に字幕がクリックを吸う問題は解消した（字幕の上をクリックしても送れる）。

## A1「1 回目で全表示・2 回目で次へ」（実装済み・未ビルド）

**決定（2026-09-30）:** クリック待ちの外でクリックしたら、**既定では次の待機位置へジャンプ**する。設定で「何もしない」も選べる（Config の `ClickOutsideWait`）。

### 動き
| 状況 | クリックしたとき |
|---|---|
| Stop 区間で、タイプライターが表示途中 | 待機位置（区間の終わりの直前）へジャンプし、全文を表示して待つ |
| Stop 区間で、全文を表示済み・区間の終わりで待機中 | 区間の後ろへ進む |
| Loop 区間 | 区間の後ろへ進む |
| 待機の外 | 次の待機へジャンプ（Stop なら待機位置、Loop なら先頭）。設定で「何もしない」にもできる |

### 実装で決めたこと
- 「全文を表示済みか」は、SequencerSubtitles の `IsTypewriterRevealing()`（今回追加）で判定する。
  - タイプライターを使っていない行は、1 回のクリックで次へ進む（ADV の標準的な動き）。
  - **CinematicADV は SequencerSubtitles v1.4（未リリース）が必要になる。**
- 次の待機は、シーケンス自身とその直下のサブシーケンス／ショット（1 階層）の Click Wait から探す。2 階層以上の入れ子と、再生速度 1 以外は未対応。
- 待機の外のクリックを受け取れるよう、Click Wait を含むシーケンスが再生を始めたら 0.25 秒以内に検出して、入力を有効にする（LevelSequenceActor を定期的に走査）。

### 確認してほしいこと
- ビルド（特に `PlayTo` / `FMovieSceneSequencePlayToParams::bExclusive`、`IMovieScenePlayer::AsUObject`）
- タイプライター表示中の 1 回目、表示し終わった後の 1 回目、待機の外のクリック、ショットの中の待機への移動
- Stop / Loop が区間の終わりで正確に止まるか。次の台詞や音声が一瞬出ないか
- 同じレベルで 2 本目のシーケンスを再生したとき、レベルを移動した後、ショットの中の Click Wait
- カットシーンの外で、同じキーがゲーム側に届くか
- スキップの後にフェードで戻るか
- パッケージ版での入力

## A2 オートモード（実装済み・未ビルド）

**決定（2026-09-30）:**
- 待ち時間は「基本の待ち時間 ＋ 1 文字あたりの時間 × 文字数」。
- ボイスあり・なしの両方に対応する。
- ON/OFF は、入力アクション（キー）と Blueprint の両方でできるようにする。

### 動き
- オートが ON のとき、待機に着いて、全文が表示し終わってから、次の時間が経ったら自動で次へ進む。
  - Stop: 区間の終わりで一時停止した時点から数える。
  - Loop: 区間に入った時点から数える（ループは続けたまま）。
- **ボイスなし:** `AutoBaseDelay`（既定 1.0 秒）＋ `AutoDelayPerChar`（既定 0.05 秒）× 文字数
  - 文字数は、待機中に画面に出ている Sequencer Subtitles の台詞（空白・改行は数えない）。
  - シーケンスに台詞がないとき（ShowMessage など）は、今表示中の字幕の文字数を使う。
- **ボイスあり:** ボイスが終わるまで待ち、さらに `AutoDelayAfterVoice`（既定 0.5 秒）待つ。
  - 対象のボイスは、前の待機を出てから、この待機の終わりまでに始まるもの。
  - ボイスの終わりは、サウンドの長さとセクションの終わりの早いほう。
- クリックは、オート中もこれまでどおり使える。クリックしてもオートは OFF にならない。
- オートは、OFF にするまで ON のまま（次のシーケンスにも引き継ぐ）。
- ゲームの一時停止中は進まない（subsystem の Tick が止まるため）。

### 実装で決めたこと
- **ボイスの見分け方:** オーディオセクションのサウンドで判定する。どちらかに当てはまればボイスとみなす。
  - `VoiceSoundClasses`: サウンドクラス（親クラスも含めて）が一覧にある。
  - `VoiceAssetKeywords`: アセットのパスにキーワードが含まれる（大文字小文字は区別しない。既定は `Voice` と `VO_`）。
  - トラックの表示名は、パッケージ版には残らないため使わない。
- 待機の外のクリックで次の待機へジャンプした場合、飛ばしたボイスは聞いていないので、ボイスなしとして待つ。
- セクションの走査を `ForEachSectionInRootTime` にまとめ、次の待機の検索（A1）と共通にした。
  - オブジェクトのトラックも含めるようにした。ミュートしたトラックは除く（次の待機の検索でも除く）。
- BP: `SetAutoMode` / `ToggleAutoMode` / `IsAutoMode`、イベント `OnAutoModeChanged`（「AUTO」の表示などに使う）。
  - 「AUTO」の表示そのものは、プラグインでは出さない（ゲームごとに UI が違うため）。

### 気になっていること（要確認）
- Stop の待機で一時停止すると、UE の仕様で**音声も止まる可能性がある**（記憶ベース、未確認）。
  - その場合、ボイスは待機の終わりより前に終わるように置く必要がある（手動のクリックでも同じ）。
- ボイスの長さは、セクションの開始オフセット、ピッチ、サブシーケンスの再生速度を考えていない。

### 確認してほしいこと
- ビルド（特に `USoundBase::GetSoundClass` / `IsLooping` / `GetDuration`、`USoundClass::ParentClass`、`UMovieSceneTrack::IsEvalDisabled`、`FMovieSceneBinding::GetTracks`）
- ボイスなし: 文字数に応じて待つ時間が変わるか
- ボイスあり: ボイスが終わってから進むか。ボイスがサウンドクラスまたはパスで見分けられるか
- Loop の待機、ショットの中の待機、オート中のクリック、ゲームの一時停止中
- キーでの ON/OFF と、`OnAutoModeChanged`

## A3 バックログ（実装済み・未ビルド）

**決定（2026-09-30）:**
- 画面: **簡易 UI ＋ BP 用のデータ**（設定で組み込み UI を OFF にすれば、自作の UMG で出せる）
- ボイス: バックログから**再生し直せる**
- 巻き戻し（行を選んでその場面へ戻る）: **今回は入れない**（イベントやゲーム側の処理がやり直しにならず、状態がずれやすい）。セーブ/ロードの後で再検討する。
- 記録の保持: **ゲームの起動中ずっと**（シーケンスをまたいで残す。上限件数あり）。保存はセーブ/ロードの段階で行う。

### 記録
- Sequencer Subtitles の `OnSubtitleSlotStarted` で記録する（話者名・本文・ボイス）。
- 記録するのは、**ADV のシーケンス（Click Wait を含む）の再生中だけ**。
  - それ以外の台詞（ShowMessage など）は、BP の `AddBacklogEntry` でゲーム側から足せる。
- 同じ台詞が続けて始まった場合（Loop で同じ区間を繰り返したときなど）は、1 件にまとめる。
- ボイス: 台詞のセクション（SlotID ＝ セクションの UniqueID）と重なるボイスのうち、開始が台詞の開始にいちばん近いもの（台詞の開始の 0.25 秒前から、台詞の終わりまで）。ボイスの判定はオートと同じ。
- 上限: Config の `MaxBacklogEntries`（既定 200）。超えたら古い順に消す。

### 開く・閉じる
- Config の `BacklogAction`（キー）で開閉する。BP の `OpenBacklog` / `CloseBacklog` / `ToggleBacklog` でもできる。
  - マウスホイールで開きたい場合は、IMC で Mouse Wheel Up を `BacklogAction` に割り当てる。
- 開いている間は、シーケンスを一時停止する。オートも止まる。閉じると再開する。
- 開いている間のクリック（AdvanceAction）は、バックログを閉じる。スキップは受け付けない。

### 組み込み UI（`bUseBuiltInBacklogUI`、既定 ON）
- 画面全体を暗くして、台詞を上から古い順に並べる（開いたときは一番下＝最新を表示）。
- 各行: ボイスがあれば再生ボタン、話者名、本文。
- フォント（`BacklogFont`、未設定ならエンジン既定）、文字サイズ、色は Config で変えられる。
- マウスで操作できるように、開いている間はマウスカーソルを出す（`bBacklogShowMouseCursor`、既定 ON）。閉じたら元に戻す。

### BP
- `GetBacklogEntries` / `ClearBacklog` / `AddBacklogEntry`
- `OpenBacklog` / `CloseBacklog` / `ToggleBacklog` / `IsBacklogOpen`
- `PlayBacklogVoice(Index)` / `StopBacklogVoice`
- イベント: `OnBacklogEntryAdded` / `OnBacklogOpened` / `OnBacklogClosed`

### 実装で決めたこと
- **記録のタイミング:** 新しいワールドのアクターが BeginPlay する前（`FWorldDelegates::OnWorldInitializedActors`）に、Sequencer Subtitles のイベントに登録する。
  - 最初のフレームから再生されるシーケンスの、1 行目も取りこぼさないため。登録し損ねた場合は Tick でも登録する。
  - 台詞が始まった時点で ADV のプレイヤーがまだ見つかっていなければ、その場で探す（0.25 秒ごとの検出を待たない）。
- **同じ台詞をまとめる範囲:** 同じ待機の中で、同じ字幕セクションがもう一度始まった場合だけ。待機を抜けたら、同じセクションでも新しい行として記録する。
- **一時停止からの再開:** 待機の区間の途中で開いた場合は、閉じたときに区間の終わりまでの `PlayTo` をかけ直す（一時停止で止める位置が消えるため）。
- **マウスカーソル:** 開いている間は、カーソルを出して入力モードを Game and UI にする。閉じたらカーソルを元に戻し、もともと隠れていた場合は入力モードを Game Only にする。
  - 元の入力モードは UE から取得できないため、「カーソルが隠れていたゲームは Game Only」とみなしている。
- **操作:**
  - クリック（AdvanceAction）で閉じる。ボイスのボタンとスクロールバーの上では閉じない。
  - ホイールはバックログの中で止める（BacklogAction にホイールを割り当てた場合に、一番上までスクロールしたところで閉じないようにするため）。
  - キーボード・ゲームパッドでのスクロールは、組み込みの UI では未対応。
- **ボイスの再生:** `SpawnSound2D`。前に再生したボイスは止める。閉じたときも止める。
- 開いたままスキップ（BP の `Skip`）した場合は、バックログを閉じてからスキップする。

### 確認してほしいこと
- ビルド（特に `FWorldDelegates::OnWorldInitializedActors`、`UWorld::FActorsInitializedParams`、`FSlateFontInfo`、`SScrollBox::ScrollToEnd`、`SetShowMouseCursor`）
- 1 行目（シーケンスの最初のフレームの台詞）が記録されるか
- Loop の待機で、同じ台詞が何度も記録されないか
- ボイスの紐づけ（台詞とボイスの開始がずれている場合も）と、再生・停止
- 開閉とシーケンスの一時停止・再開（待機中、待機の途中、待機の外）、オート中に開いた場合
- マウスカーソルと入力モードが、閉じた後に元どおりになるか
- 再生ボタンの「▶」が表示されるか（既定のフォントにない場合は `BacklogFont` を設定する）

## A4 早送り・既読スキップ（実装済み・未ビルド）

**決定（2026-09-30）:**
- 操作: **押している間＋切り替えの両方**（キーと BP）
- 進め方: **高速再生**（再生速度を上げ、待機はすぐに通過する）。早送り中は音声をミュートする。
- 未読: **止まる**。プレイヤーの設定で「未読も飛ばす」を選べる。
- 既読の保存先: **専用のシステムデータ**（セーブスロットとは別の SaveGame。どのセーブで遊んでも共通）

### 既読の管理
- 台詞は、字幕セクションのパス名で区別する（パッケージ版でも同じ）。
  - エディタでセクションを消して作り直すと、その台詞は未読に戻る。
  - 同じサブシーケンスを 2 回使った場合は、同じ台詞として扱う。
- 台詞が画面に出た時点で既読にする（読む前に既読かどうかを調べてから記録する）。
- 保存: 変更があれば 10 秒ごと、シーケンスの停止時、終了時に書き込む（非同期。終了時だけ同期）。
- BP: `ClearReadHistory`（既読をすべて消す）

### 早送り
- Config:
  - `FastForwardAction`（押している間）
  - `FastForwardToggleAction`（切り替え）
  - `FastForwardRate`（既定 8 倍）
  - `FastForwardAudio`: 全部ミュート（既定）/ ボイスのサウンドクラスだけミュート / そのまま
- 早送り中は、待機に着いたらすぐに次へ進む（オートより優先）。
- 未読の台詞が出たら早送りを止める。
  - 切り替えは OFF になる。押している間の場合は、一度離すまで止まる。
- 切り替えは、ADV のシーケンスが終わったら OFF に戻す（ゲームに戻った後の次のシーケンスで、いきなり早送りにならないように）。
- バックログを開いている間は、早送りしない。
- BP: `SetFastForwardMode` / `IsFastForwardMode` / `IsFastForwarding`、イベント `OnFastForwardChanged`（「SKIP」の表示などに使う）

### プレイヤーの設定
- 「未読も飛ばす」は `UADVUserSettings`（GameUserSettings.ini）に保存する（Sequencer Subtitles のプレイヤー設定と同じ方式）。
- BP: `SetSkipUnread` / `GetSkipUnread`（変更すると、すぐに保存する）

### 実装で決めたこと
- 未読で止めるのは、次の Tick（次のフレームの評価より前）。台詞の最初の 1 フレームだけは早送りの速度で進む。
- 「全部ミュート」は、オーディオデバイスの一時的な音量（`SetTransientPrimaryVolume`）を 0 にする。BGM も止まる。
  - 「ボイスのサウンドクラスだけ」は、実行時に作ったサウンドミックスで、`VoiceSoundClasses` の音量を 0 にする。
  - キーワード（`VoiceAssetKeywords`）で見分けているボイスは、この方法ではミュートできない。
- 早送りをやめたとき、ミュート中に始まったボイスは途中から聞こえる。
- 早送りを BP で先に ON にしておくと、次の ADV のシーケンスが始まったときから早送りになる。

### 気になっていること
- 高速再生中の Sequencer の音声の扱い（再生速度 1 以外でどう鳴るか）は未確認。そのため、既定では全部ミュートにした。
- オートの速さを、プレイヤーが変えられる設定はまだない（今は Config の作者向けの値だけ）。必要なら `UADVUserSettings` に足す。

### 確認してほしいこと
- ビルド（特に `FAudioDevice::SetTransientPrimaryVolume` / `GetTransientPrimaryVolume`、`UGameplayStatics::SetSoundMixClassOverride`、`AsyncSaveGameToSlot`）
- 押している間・切り替え・BP での早送り。待機がすぐに通過されるか
- 未読の台詞で止まるか。「未読も飛ばす」を ON にしたとき
- 既読が、ゲームを再起動しても残るか（`Saved/SaveGames/CinematicADV_System.sav`）
- 早送り中と終わった後の音声（3 つの設定それぞれ）
- 早送り中にバックログを開いたとき、シーケンスが終わったとき

## A5 セーブ／ロード（実装済み・未ビルド）

**決定（2026-09-30）:**
- 画面: **BP 関数だけ**（保存、読み込み、スロットの情報＝日時・最後の台詞・サムネイル）。画面はゲームごとに UMG で作る。
- 別のレベルのセーブ: **レベルを開き直して再開**する。
- ゲーム側の状態: **キーと値をセーブに含める**（文字列・数値・フラグ）。選択肢の記録にも使う。
- バックログ: **セーブに含める**。

### 前提（ユーザーに説明済み）
- 保存した位置へジャンプして再開する。カメラや位置など、Sequencer が動かしているものはその時点の状態になる。
  - それより前の **Event Track（BP のイベント）は実行し直されない**。イベントで変えた状態は、キーと値で保存してもらう。
- 再開できるのは待機の位置から（Stop は全文表示で待つ位置、Loop は区間の先頭）。
  - 待機の外で保存した場合は、その時刻から再生を続ける。

### 保存する内容（`UADVSaveGame`）
- 日時、レベル（パッケージのパス）、シーケンス（アセットのパス）、シーケンスのアクター名
- 再生位置、待機中かどうか、待機の区間
- バックログ、キーと値、最後の台詞（スロット一覧用）、サムネイル（PNG）
- スロット名: Config の `SaveSlotPrefix`（既定 `CinematicADV_Slot_`）＋番号

### 読み込み
- キーと値とバックログは、すぐに戻す（新しいレベルの BeginPlay から読めるように）。
- **同じレベルでも、レベルを開き直す**（私の判断）。
  - 再生中の別のシーケンスや、ゲームで動いたものが残らないようにするため。
- レベルの BeginPlay の後の最初の Tick で、シーケンスを探して再開する。
  - 探し方: 同じシーケンスで同じ名前のアクター → 同じシーケンスのアクター → 見つからなければ新しく作る。
  - 新しく作った場合、配置したアクターのバインドの上書き設定などは引き継がれない。
- シーケンスのアクターが Auto Play の場合、BeginPlay で 0 フレーム目が一度評価される（0 フレーム目のイベントは実行される）。
- ゲームが BeginPlay で自分でシーケンスを始める場合は、`IsLoadingGame` を見て止めてもらう。

### サムネイル
- `CaptureSaveThumbnail` で、今の画面（UI なし）を撮る。撮影は次のフレームで終わる。
  - セーブ画面を開く**前**に呼んでもらう（セーブ画面が写らないように）。
- 幅は Config の `ThumbnailWidth`（既定 320）。

### BP
- `SaveGameToSlot` / `LoadGameFromSlot` / `DoesSaveSlotExist` / `DeleteSaveSlot` / `GetSaveSlotInfo` / `CaptureSaveThumbnail` / `IsLoadingGame`
- `SetStringVariable` / `GetStringVariable`、`SetNumberVariable` / `GetNumberVariable`、`SetFlag` / `GetFlag`、`ClearVariables`
- イベント: `OnGameSaved` / `OnGameLoaded`（再開した後）

## ボイス用サウンドクラス・ボイス音量（実装済み・未ビルド。SC_Voice はユーザー待ち）

**決定（2026-09-30）:**
- `SC_Voice`（サウンドクラス）は、**ユーザーがローカルの UE 5.7 で作って push する**（ここでは .uasset を作れないため。Git でやりとりする）。
  - 置き場所: `Content/Audio/SC_Voice.uasset`（プラグイン内。パスは `/CinematicADV/Audio/SC_Voice`）
- コンテンツブラウザでサウンドを右クリック → **「ボイスに設定」**（選んだサウンドのサウンドクラスを、まとめてボイス用にする）
- プレイヤー向けの**ボイス音量**を付ける。

### 実装方針
- Config の `VoiceSoundClasses` の既定値を、同梱の `SC_Voice` にする（C++ のコンストラクタで設定）。
  - 既存の `DA_CinematicADVConfig` は、この項目を保存していないので、既定値（`SC_Voice`）がそのまま使われる。アセットを開いて設定し直す必要はない。
- 右クリックのメニュー: `VoiceSoundClasses` にあるサウンドクラスごとに項目を出す。元に戻せる操作にする。
  - Config が見つからない、または一覧が空の場合は、メニューに説明の項目を出す。
- Config の探し方（プロジェクト設定 → AssetRegistry）は、ランタイムとエディタで共通の関数にまとめる（`UCinematicADVConfig::FindConfig`）。
- ボイス音量: `UADVUserSettings::VoiceVolume`（0〜1、GameUserSettings.ini）。BP の `SetVoiceVolume` / `GetVoiceVolume`。
  - 実行時に作ったサウンドミックスで、`VoiceSoundClasses` の音量を変える。ワールドごとに適用し、ワールドの破棄時に外す。
  - 早送りのミュート（ボイスのサウンドクラスだけ）とは、掛け算で重なる。

### A5・ボイスの実装で決めたこと
- セーブ中（`LoadGameFromSlot` の後、再開まで）は、`SaveGameToSlot` を受け付けない（false を返す）。
- 保存した待機が見つからない（シーケンスを編集して待機を動かした）場合は、保存した時刻から再生を続ける。許容誤差は 1 フレーム。
- スロットの情報は、セーブを丸ごと読んで返す（サムネイルもその場でテクスチャにする）。スロット数が多いと、一覧を開くときに少し止まる可能性がある。
- サムネイルは、撮り直すまで使い回す。セーブ画面を開くたびに `CaptureSaveThumbnail` を呼んでもらう。
- 変数は `FADVVariables`（文字列・数値・フラグの 3 つの Map）。`GetAllVariables` でまとめて取れる。
- ボイス音量は、ワールドが始まるとき（アクターの初期化時）に適用し、ワールドの破棄時に外す。
- Config の探し方を `UCinematicADVConfig::FindConfig` にまとめ、ランタイムと右クリックのメニューで共通にした。
- `SC_Voice` がまだないので、今は Config の既定値の読み込みで「見つからない」というエラーがログに出る。push してもらえば消える。
